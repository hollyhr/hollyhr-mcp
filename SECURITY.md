# Security

Please do not report a vulnerability through a public GitHub issue.

Use the security contact published on the
[HollyHR security page](https://www.hollyhr.com/security). Include the affected
URL, the behaviour you observed, the potential impact and safe reproduction
steps. Do not include real employee records, credentials, access tokens or API
keys.

The hosted endpoint, OAuth flow, permissions and data handling are governed by
HollyHR's current product terms, privacy notice and security documentation.
This repository contains discovery documentation only.
